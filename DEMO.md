## 4 · Reproduce everything

```bash
git clone https://github.com/edycutjong/labelme && cd labelme && npm install   # ≈ 10 s
npm run labelme -- play --seed meridian --answers   # section 1, 0 credits
npm run verify                                       # 62/62 cards reproduced offline, 0 network
npm test                                             # 94 tests, no key
npm run reader                                       # the house rule's confusion matrix on the deck
export NANSEN_API_KEY=nsn_…
npm run labelme -- draw --explain                    # section 2, ≤ 13 credits
npm run bench -- --runs 10                           # section 3, ≈ 130 credits
npm run dev                                          # http://localhost:3200 — the game; "Draw fresh" is the only live button
```

`npm run seed` rebuilds the deck live (≈ 550 credits) — not needed to play; the committed deck is the product's deck. After an output-only engine change (tell wording), `npm run verify -- --update` rebuilds every card from the untouched recorded responses at 0 credits.
